Бесплатный Впн для подключения к интернету

Порядок действий:

1. Скачиваете ZIP-файл под названием "sing-box.zip", и делаете разархивацию, и перекидываете папкусо всем содержимым в корень диска "C"
2. Скачиваете файл TXT для того чтобы он у вас просто был, и неприходилось искать все заного, можете сохранить его на рабочем столе.
Следующим будет ваше действие:
1. Открываете "CMD" от имени администратора, сам порядок действий очень прост, нажимаете "Win+R", дальше пишете "cmd", потом зажимаете "CTRL+SHIFT" и нажимаете "ENTER", выйдет окно подтверждения.
2. Открывается командная строка и вы будете находить на пути C:\Windows\System32>, вводите "cd C:\", и вы выходите в корень диска "C:\".
3. Дальше нужно открыть с вашего рабочего стола TXT-файл под названием "КОД.txt", в текстовике будет небольшой список, в команд, в командной строке вы дальше вводите cd sing-box из текстовика, у вас запускаетс программа sing-box.
4. Потом вводите любой из четырех кодов, к примеру .\sing-box.exe run -c estonec.json, у вас запускается этот файл и где окна подключения к интернету добавится новое подключение "tun0", считая на этом этапе у вас установленно подключние, не забываем потом подключиться к интернету, для проверки можно зайти по адресу "https://ipinfo.io/json" там покажет подключение.

Теперь перейдем к минусам:

Минусов немного:

1. И наверное самое главное у вас не будет работать без подключения к интернету, если вы находитесь там где блокируют интернет ивводят только белые списки у васне получится сделать подключение.
2. Может перестать работать одна из команд, когда вы введете последнюю команду ".\sing-box.exe run -c estonec.json", если нет подключения к интернету или что-то другое уваспросто вылезет ошибка, вы после этого можете просто вставить другую команду и программапопробует сделать повторное подключение, не обязательно закрывать командную строку после неудачного подключения или если вы неправильнно ввели команду.
3. Перейдем к теме про закрытие командной стороки, ни при каких обстоятельствах не закрывайте командрную строку, просто сверните ее и всё, если закроете придется писать все заного, после выключения системы естественно тоже самое, при переходе в режим сна приложения не закрываются а следовательно ком.строка тоже не закроется.
